Website giới thiệu và đặt hàng chính thức của cơ sở **Heo Quay Hiếu** tại Mỏ Cày, Vĩnh Long. Trang web cung cấp trải nghiệm mượt mà, tối ưu hóa giao diện di động và chuẩn Responsive 5.0.

---

## 🌟 Tính Năng Nổi Bật (Giao diện 5.0)

- **📱 Tối ưu hóa Mobile First:** Giao diện mượt mà trên mọi thiết bị di động, máy tính bảng và máy tính bàn.
- **🌗 Chế độ Tối/Sáng (Dark/Light Mode):** Cho phép người dùng chuyển đổi giao diện linh hoạt.
- **⚡ Thanh điều hướng nhanh (Mobile Dock):** Tích hợp nút Gọi điện (`tel:`) và Zalo trực tiếp ở đáy màn hình.
- **✨ Hiệu ứng Glassmorphic:** Sử dụng hiệu ứng kính mờ hiện đại, tạo cảm giác sang trọng.
- **🗺️ Bản đồ Google Maps:** Tích hợp trực tiếp vị trí cửa hàng tại Ấp 3, QL60, Mỏ Cày, Vĩnh Long.

---

## 🛠️ Công Nghệ Sử Dụng

- **HTML5 & JavaScript Vanilla**
- **Tailwind CSS v3** (Cung cấp qua CDN)
- **Lucide Icons** (Bộ icon tối giản, sắc nét)
- **Plus Jakarta Sans** (Google Fonts)
