# 🐖 Heo Quay Hiếu - Landing Page & Nhật Ký Hoạt Động (2026)

Trang web giới thiệu dịch vụ và nhật ký hoạt động cho **Cơ sở Heo Quay Hiếu** tại Mỏ Cày, Vĩnh Long. Dự án được xây dựng theo phong cách hiện đại, tối ưu tốc độ phản hồi (High Performance) và thân thiện với thiết bị di động.

## 🌟 Tính Năng Nổi Bật

- **Giao Diện Hiện Đại (Modern UI):** Sử dụng thiết kế Glassmorphism mịn màng, font chữ `Plus Jakarta Sans` hợp xu hướng 2026.
- **Chế Độ Sáng/Tối (Dark Mode Support):** Tự động chuyển đổi hoặc tùy chỉnh giao diện Light/Dark Mode theo người dùng.
- **Tương Thích Thiết Bị Di Động (Mobile-First):** Thiết kế tối ưu cho mọi kích thước màn hình, tích hợp thanh tác vụ nhanh (Gọi điện/Zalo) cố định ở viền dưới màn hình điện thoại.
- **Trình Quản Lý Bài Viết (Mini Feed / Feed Blog):**
  - Đăng tải bài viết kèm hình ảnh hoặc video hoạt động từ máy tính/điện thoại.
  - Sử dụng `FileReader API` để mã hóa và xem trước nội dung trực tiếp.
  - Lưu trữ dữ liệu bài viết tiện lợi qua `LocalStorage`.
- **Đạt Chuẩn SEO & Accessibility:** Đã bổ sung các thuộc tính `aria-label`, `alt` và cấu trúc Semantic HTML chuẩn Google Search 2026.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend Core:** HTML5, CSS3, JavaScript (ES6+ Vanilla).
- **Styling:** [Tailwind CSS CDN v3.x](https://tailwindcss.com/)
- **Icon Library:** [Lucide Icons](https://lucide.dev/)
- **Font:** Google Fonts (`Plus Jakarta Sans`)
- **Map:** Google Maps Embedded API
